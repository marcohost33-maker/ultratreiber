# UDX reusable CodeFactory patterns (candidate, no global import)

- **CF-UDX-FRAME-BOUNDS-v1**: 4-byte network-order length; byte cap before allocating or parsing body; malformed/truncated connection never executes an operation. Negative tests oversized advertised length without body, partial header, partial body, odd UTF-8.
- **CF-UDX-OS-PEER-v1**: authenticated UID via kernel SO_PEERCRED on connected AF_UNIX only; refuse missing/invalid OS credentials; sender JSON fields never grant privileges. Limit: UID != application identity.
- **CF-UDX-PRIVATE-ENDPOINT-v1**: owner-controlled 0700 runtime dir, new 0600 socket; refuse unknown existing path; no path-based socket takeover; bounded shutdown checks inode before unlink. Limit: abnormal kill leaves stale socket.
- **CF-UDX-CONTRACT-PARITY-v1**: JSON Schema 2020-12 + golden request/response vectors with negative oracle; ensure required conformance dependency is installed. JSON Schema alone cannot distinguish repeated key pairs.
- **CF-UDX-REPLAY-SCOPE-v1**: process-local bounded replay controls only a read-only proof; never use as a durable exactly-once guarantee.

- **CF-UDX-DK-RUNNER-v1** (W26.1): discriminating mutations are evidence only if reproducible: mutate a private copy, never the checkout; no bytecode cache (`-B`, `PYTHONDONTWRITEBYTECODE`; `.pyc` is validated by mtime seconds + size); byte I/O (no CRLF translation); anchor exactly once (stale = finding, not skip); baseline green and not skipped; a timeout or skip is never a kill; spec paths confined to the copy. Limit: a kill by a source-text pin proves the pin, not the runtime behaviour. A refusal-only oracle kills "refuse everything" mutants only by accident of the host (W26.1: 12/14 on an elevated runner); pair every refusal with the case that must be accepted.
- **CF-UDX-IL-EQUALITY-v1** (W26): a local IPC client accepts an endpoint only if its mandatory label EQUALS the client's own effective integrity level (after the owner check). Rationale: a lower-level squatter can copy owner, DACL and its own label, so only the level separates it; higher labels are already refused at open by the token's NO_WRITE_UP policy. Limit: needs the default token mandatory policy; no server authentication (G2-App).
- **CF-UDX-PHASED-CHILD-START-v1** (W27): a parent that hands work to a freshly started child waits for an explicit readiness signal (one byte on a private pipe) under its own liveness budget, and only then starts the protocol exchange under the protocol timeout. Each phase has a typed failure; EOF on the readiness pipe is "child died", never "ready"; every failure path kills and reaps the child. A socket adopted from another process gets its timeout set explicitly (the blocking mode belongs to the shared open file description, not to the new socket object). Limit: the readiness byte says the child reached that line, not that it is correct. Negative tests: slow start beyond the protocol timeout, never ready, exit before ready, ready but silent, late parent send.
- **CF-UDX-GUARD-SWEEP-v1** (W27): two-sided mutation of every refusal taken from the code (`if ... raise`): remove it (needs a negative test) and force it (needs a positive control). Survivors are pinned with class and reason; a new survivor and a pin that no longer survives both fail. Same hygiene as CF-UDX-DK-RUNNER-v1. Limits: sees only `if ... raise`; a kill by a wrong exception type is weaker than a failed assertion; equivalent mutants need a human reason.
- **CF-UDX-GUARD-SWEEP-v2** (W28): extends v1 to refusals written as `if ... return <refusal>` (ADMIT/REFUSE) and to `except` handlers that convert an exception into a typed refusal (mutant UNTYPED: `except ():`, the original exception escapes). A kill must be attributable: a failed assertion or an error inside a test method; import, `setUpClass`/`setUpModule` and teardown errors are STRUCTURAL and never count. Each kill records its mode and the failing tests. A pin of class EQUIVALENT must name an existing witness test. W28.1: mutants force the result but keep evaluating the condition (`((cond) and False)` / `((cond) or True)`), because a condition may carry a side effect (`sock.send`); every kill is confirmed by re-running its failing tests alone (`UNRELIABLE` otherwise). Limits: a refusal-valued return is recognised by shape (upper-case code string, `False`, call with a literal `False`), not by meaning; `assert` is covered by a static ban, not by mutation.
- **CF-UDX-FINITE-NUMBER-v1** (W28): a clock or deadline accepted as `int` or `float` is checked with a helper that treats `OverflowError` from `math.isfinite` as "not finite" (an int beyond the float range), and a value stored in a bounded integer column (SQLite: signed 64 bit) is range-checked including the largest addition made to it. Refuse typed; never guess. Negative tests: `10**400`, `2**1024 - 2**970 - 1` (passes the clock check, overflows after `+ 300`), `MAX + 1`; deterministic property corpus.
- **CF-UDX-LAZY-PLATFORM-CONSTANTS-v1** (W28): platform constants that a given interpreter build may lack (here `fcntl.F_SEAL_*` in a Clang build of CPython 3.13.18) are resolved at use, not at import, and their absence is a typed refusal before any input is read. An import must never fail because of an optional capability; tests that need the capability skip with that reason.

Transfer rule: copy only after matching trust boundaries and a named owner verifies independent implementation plus tests; no automatic promotion into CodeFactory runtime.
